# AI-Based Phishing Website Detection System

An AI-powered phishing website detection system developed using Machine Learning and Flask.

## Features
- Real-time phishing URL detection
- Random Forest classifier
- URL feature engineering
- Flask web deployment
- Confidence score prediction
- Trusted-domain validation

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Machine Learning Features
- URL Length
- HTTPS Presence
- Suspicious Keywords
- Domain Length
- Entropy Analysis
- Character Diversity
- Subdomain Detection
- Similarity Analysis

## Model Performance
- Accuracy: 90.62%
- Weighted F1-Score: 0.91
